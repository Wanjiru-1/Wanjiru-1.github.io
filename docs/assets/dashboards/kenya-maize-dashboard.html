What this evidence supports

Persistence has the lowest MAE in all three markets. Random Forest has a slightly lower RMSE in Nairobi. This small descriptive difference does not establish a statistically reliable advantage.

Models were evaluated on the same available dates within each market. Missing observations and lag features reduce coverage; dates differ across markets. The backtest assumes earlier monthly prices were available and does not model publication delays or revisions.

This is not a live price service. These results do not establish current forecasting accuracy, causes of price movements, retail prices or measured food-security impact.

The AI experiment

A Random Forest model was trained and compared with persistence and seasonal baselines. A local Qwen2.5-1.5B-Instruct assistant was then tested for explaining the results.

The assistant confused metric definitions, misrounded a value and added unsupported wording. This dashboard therefore displays facts directly from structured records. No live LLM runs on this page.

Read the evaluation findings

Version 2 tested six generated explanations. All named the right winning model, but two confused MAE and RMSE. Five omitted the market name. The Python lookup separately rejected Mombasa, an unevaluated market. These are small development tests, not general accuracy estimates.

Source references shown here are application-generated; they are not evidence of model citation ability. Versions 1 and 2 used different test sets, so improvement percentages would be misleading.
